# DIR HELPER

Дополнение Firefox для CRM МНЧ + Telegram-бот.

- `ext/` — код дополнения. Номер версии — в `ext/manifest.json`.
- При каждом изменении `ext/` GitHub сам подписывает дополнение на addons.mozilla.org
  и выкладывает новую версию в «Releases». Firefox обновляется сам (раз в сутки
  или сразу: about:addons → ⚙ → «Проверить наличие обновлений»).
- Токен бота в коде НЕ хранится — он только в настройках дополнения в Firefox.
