## Тёмная тема
- Кнопка ☀/☾ (theme.js) открывает меню тем (DH_THEMES). storage `dhTheme`: light (обычная) | светлые breeze/skywhite/rose/lavender/sage/sunny (старый ключ sky → breeze) (класс `html.dh-lt`, переменные --dh-l*, LIGHT/deriveLight/mapLight в gen-dark.mjs: фон/серые рамки/зелёные бренда, текст не трогаем) | dark (ночной Telegram) | midnight/forest/obsidian/emerald/purple. Тёмные ставят класс `html.dh-dark`, палитры — ещё `data-dh-pal`. Правила обоих классов лежат в тех же dark-*.css. Все тёмные цвета — CSS-переменные `--dh-*` (bg0…bg4, line, ink, muted, acc*…); наборы переменных на палитру — PALETTES/derive() в gen-dark.mjs (5 цветов палитры → роли), «ночной Telegram» — TG_NIGHT. Зелёные бренда в окнах дополнения → акцент палитры. Новая палитра = добавить в PALETTES и DH_THEMES. Цвета: dark-crm.css (CRM), dark-ext.css (panel/dashboard), dark-sidebar.css (окно) — ГЕНЕРИРУЮТСЯ `cd .tools && npm i && node gen-dark.mjs` из .tools/crm-css/*.css (стили CRM, сохранены из кэша Firefox), panel.css, dashboard.css, sidebar.css + ручные .tools/*.manual.css. Поменяли panel/dashboard/sidebar.css — перегенерировать. Палитра: ночной Telegram (#0e1621/#17212b/#1e2c3a) + зелёные акценты.
- Ячейки с цветной заливкой (статусы) в тёмных И светлых палитрах: theme.js ставит `dh-lit` + `--st-bg/--st-fg/--st-dot`, оборачивает текст в span.dh-pill («таблетка» во всю ячейку, без точки; ячейки с полями/кнопками не оборачивает): известные статусы — ST_D (тёмные) / ST_L (светлые) в theme.js, прочие — оттенок исходной заливки. ## Подводные камни
- В Firefox НЕТ runtime.requestUpdateCheck, а about:addons дополнению не открыть. Кнопка «Обновить» (dhUpdateCheck) сверяет версию с updates.json (dhLatest в tg.js) и возвращает ссылку; .xpi ставится ТОЛЬКО по клику человека (xpinstall.userActivation.required) — поэтому ссылка «⬇ Установить» (dhUpdLink/dhUpdToast в changelog.js), а не tabs.create (так установка молча не стартовала, 14.1–14.4). Найденная версия → storage dhUpdAvail → красная точка на «?».
- runtime.onMessage: НЕ делать обработчик `async` — он вернёт Promise на любое сообщение и «перехватит» ответ у других обработчиков (так ломались ⟳ «Обновить» и т.п.). Нужное сообщение → `return promise`, чужое → `return` без значения.
- В регулярках с кириллицей не использовать `\b`.
- Не использовать spread по URLSearchParams в content script.
- Статус в CRM может быть с пометкой «(Отз)» — сравнивать через stKey.
- Поле токена в настройках раньше затиралось — исправлено (TOK_DIRTY).
- Патчи JS с регулярками (\d, \s) не вставлять через heredoc/sed в bash — обратные слэши теряются (так ломался theme.js). Править через Edit.
- Список заявок: автообновление раз в 90 с (listAutoRefresh в content.js; пропускает, пока пользователь занят; storage dhListRefresh=false — выключить). «Срочная»: красный текст времени сохраняется (redText в theme.js).
