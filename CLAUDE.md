## Файлы
- manifest.json — MV2; background: tg.js + background.js (общая область видимости); content: charts.js, dashboard.js, content.js (all_frames, кроме своих скрытых iframe).
- content.js — панель на списке/заявке: «Отдать мастеру» (bgAssign), «Проведение заявки» (bgClose), смена статуса (bgStatus, bgUnassign), readReq (проверка статуса через скрытый iframe — в сыром HTML статус пустой!), обработчики сообщений dhAssign/dhStatus/dhClose/dhInfo/dhDayTurn/dhMasterStat/dhSummary.
- dashboard.js — аналитика (Отчёт по городу), ЗП директора (мотивация), реклама, рейтинг; masterStat, dayTurn, tgText.
- tg.js — бот: long polling, меню, callbacks, группы мастеров (TG.groups, нечёткое сопоставление nameScore), контроль (ctl*), мастер проведения (WIZ), /тест, утро 9:00, сводки 9:00/22:00.
- background.js — бейдж/звук новых заявок, слежение за закрытием (сумма к сдаче мастеру), сигнал «CRM недоступна».
- options.html/js — токен, галочки, «бот на этом компьютере», перенос настроек, привязка групп к мастерам.

## Правила, которые просил пользователь
- Статусы в выпадающем списке скрыты: все «Отмена…», «Готов», «Готов ОФ», «Не оформлена», «На уточнении», «Не создана». «Отказ» оставить.
- Мастеру текст заявки уходит ТОЛЬКО при «В пути» (не при «В работе»/«Ожидает»), только если статус реально записался в CRM. После заявки — «@мастер Пиши принял» с кнопкой «✅ Принял».
- «Принял» → бот: «Как зайдешь в квартиру пиши "В работе"». «В работе» от мастера → статус В пути→В работе.
- Возврат «В работе»→«В пути»: «Выберите мастера» → Сохранить (→ Ожидает) → вернуть мастера + «В пути».
- Смена статуса в боте — только с подтверждением «Да». Готов/Отказ/Отмена не менять. «✅ Провести заказ» — только у заявок «В работе».
- @tveruga: его обычные сообщения в группах мастеров игнорировать, команды выполнять; /тест — только ему и пользователям бота.
- 9:00 в группы мастеров: «Доброе утро, дорогой мастер, сегодня у тебя все получится».
- Общий чат мастеров (/общий): /стат — статистика за день + оборот, без «Работа СД».
- ЗП директора в бот НЕ выводить. Команда /отдай удалена.
